The middleman's fee becomes the public good.

Consensus

A lottery nobody can rig.

Stake-weighted VRF: cryptographic sortition, verified in milliseconds. 10% of the stake = 10% of the odds — but which ticket wins is unpredictable, unforgeable, and provable to everyone.

🎲

VRF sortition

Each round, VRF(private key, last block hash) < threshold wins block rights. Algorand/Cardano-grade randomness, zero electricity.

🧱

Simple core, forever

The L1 verifies exactly three things: signed, paid, staked. No Turing machine on-chain — exploits die in channels, never reach consensus.

🪐

Built for elsewhere

Local block production + checkpoints tolerate minutes of latency. The same rules hold on Mars — the protocol doesn't care where you are.

Cold start — RFC-003

Be there early. That's the whole trick.

Zero premine creates a puzzle: nobody owns coins, so nobody can stake. The bootstrap window solves it with pure presence.

1

Run a node

Download, start, stay online. No permission to ask for, no capital to commit.

2

Win by lottery

First K blocks: one VRF ticket per online node, equal odds for everyone. Winner mints a deliberately small coinbase.

3

Auto-stake, no locks

Bootstrap rewards are recorded as stake automatically. No expiry, no cliff, no dual tokens — idle coins simply earn nothing while active ones compound.

4

The chain graduates itself

After block K, stake-weighted VRF takes over. No announcement, no human decision — just rules executing.
